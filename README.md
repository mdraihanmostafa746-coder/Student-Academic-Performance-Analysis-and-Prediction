# Student Academic Performance Analysis and Prediction

A Python-based Data Science and Machine Learning project focused on analyzing student academic performance, identifying factors that influence examination scores, and building predictive models.

## Project Overview

This project explores student performance data using data analysis, visualization, and machine learning techniques. The goal is to understand patterns in students' academic performance and evaluate different models for predicting student outcomes.

## Objectives

- Explore and understand student performance data.
- Identify factors that may influence examination scores.
- Perform data cleaning and preprocessing.
- Apply exploratory data analysis (EDA) and data visualization.
- Build and evaluate different machine learning models.
- Compare model performance to identify suitable approaches.
- Explore patterns in student data using dimensionality reduction and clustering techniques.

## Dataset

- **Dataset:** Student Performance Factors
- **Source:** [Kaggle – Student Performance Factors](https://www.kaggle.com/datasets/lainguyn123/student-performance-factors)
- **Format:** CSV

The dataset contains information about different factors related to students and their academic performance.

## Technologies & Libraries

- **Language:** Python
- **Data Analysis:** Pandas, NumPy
- **Data Visualization:** Matplotlib, Seaborn
- **Machine Learning:** Scikit-learn

- **Environment:** Jupyter Notebook

## Installation & Setup

**1. Clone the repository**

```bash
git clone https://github.com/mdraihanmostafa746-coder/Student-Academic-Performance-Analysis-and-Prediction.git
```

**2. Navigate to the project directory**

```bash
cd Student-Academic-Performance-Analysis-and-Prediction
```

**3. Install the required libraries**

```bash
pip install -r requirements.txt
```

**4. Run the Jupyter Notebook**

```bash
jupyter notebook
```

Open `notebooks/student_performance_analysis.ipynb` to explore the complete analysis and implementation.
